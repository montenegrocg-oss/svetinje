# Додавање нове светиње

Генератор прави само минималну, непубликовану истраживачку структуру. Он не додаје мјесто у радни приказ и не мијења јавни статус.

## 1. Направите структуру

Из коријена репозиторијума покрените:

```bash
pnpm new:place manastir-savina monastery
```

По потреби можете одмах задати провјерени српски назив и одобрени slug:

```bash
pnpm new:place manastir-savina monastery --name "Манастир Савина" --slug "manastir-savina"
```

Команда прави само:

```text
content/places/manastir-savina/place.yaml
content/places/manastir-savina/narratives/sr.md
```

Не прави изворе, медијске записе, координате, одобрења нити практичне податке.

## 2. Довршите истраживачки досије

1. Попуните `place.yaml` искључиво провјереним чињеницама.
2. Додајте регистроване YAML записе извора у `content/sources/`.
3. Довршите `narratives/sr.md`; сваки материјални пасус мора имати регистрован извор.
4. Када постоји оригинална фотографија са познатим правима, додајте оптимизовану датотеку и одговарајући медијски запис. Не стављајте велике оригинале у Git.
5. Тек када су сва поља потребна за радни приказ комплетна, ручно додајте ID у `validation/editorial-preview.json`.

Валидан и allowlist-ован запис аутоматски улази у карту (само ако има координате), почетни каталог, одговарајућу категорију и сопствену детаљну страницу. За то не треба мијењати UI компоненте, број страница у тестовима, провјере рута, категорија или слика.

## 3. Провјерите локално

```bash
pnpm run check
pnpm run build
EDITORIAL_PREVIEW=true pnpm run build
```

Затим ручно покрените Cloudflare preview workflow са одговарајуће feature гране.

Радни приказ није јавна публикација. Јавно објављивање остаје закључано док запис, наратив, извори и медији не испуне све чињеничне, црквене, језичке, медијско-правне и publishing провјере описане у пројектној документацији и политици објављивања.
