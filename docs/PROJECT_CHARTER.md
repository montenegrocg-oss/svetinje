# PROJECT CHARTER — Svetinje.me

## 1. Название проекта

**Svetinje.me**

Цифровой православный путеводитель по святыням Черногории.

---

## 2. Миссия проекта

Создать современную многоязычную цифровую платформу, которая поможет паломникам, туристам и исследователям открыть православное духовное наследие Черногории.

Проект объединяет:
- монастыри;
- храмы;
- святые места;
- историческое наследие;
- духовные маршруты;
- практическую информацию для паломников.

---

## 3. Основная цель

Создать самый полный и качественный цифровой путеводитель по православным святыням Черногории.

Проект должен быть:
- достоверным;
- удобным;
- современным;
- визуально качественным;
- доступным на нескольких языках.

---

## 8. Требования к информации

Все данные должны быть проверяемыми.

Источники:
- официальные сайты епархий;
- официальные сайты монастырей;
- церковные публикации;
- архивные материалы;
- научные источники.

Запрещено:
- придумывать факты;
- публиковать неподтверждённые расписания;
- копировать чужие материалы без разрешения.
